Study Helper v1.2.8 — Loading Screen + Login Prototype

1. Extract the ZIP.
2. Open Study-Helper-v1.2.8-Loading-Login.html in a modern browser.
3. The splash/loading screen appears first. On first use, choose Create account. On later visits, the local session is remembered until Log out.
4. This is an offline prototype: account data is stored in the browser on this device. It is NOT secure server authentication, does not sync between devices, and should not be used for real payments or sensitive data.
5. Clearing browser data may remove the local account.
